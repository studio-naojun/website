INTERNAL TOOLS / GOOGLE API

Studio NaoJun Integrations

必要な予約情報を、必要なカレンダーに。NAOJUN STUDIOSが自身の業務で利用するGoogle連携アプリケーションです。

何をするアプリか

新幹線のEX予約メールから乗車日・区間・列車・座席・予約番号を読み取り、利用者が指定したGoogle Calendarに予定として登録・更新する仕組みです。予約変更・取消にも対応し、既存の予定を照合して重複登録を防ぎます。

WorkStylingの施設予約一覧も読み取り、同じGoogle Calendarに予約日時と施設名を反映する機能を備えています。業務用Windows上で動き、WorkStylingの自動予約をGoogle Cloud上で実行するものではありません。

Googleとの接続について

Googleアカウント所有者がOAuth同意画面で明示的に許可した場合のみ、Gmailの読み取りとGoogle Calendarの予定編集を行います。Gmailへの送信、メールの削除、連絡先の収集、Google Driveの読み取りは行いません。

連携するアカウントとカレンダーは所有者が設定します。一般公開サービスではなく、所有者が利用する内部ツールです。Googleアカウントへのアクセスは、所有者自身がGoogleのアカウント設定から取り消せます。

個人情報・サポート

取得するデータ、保存場所、第三者提供の有無、保存期間と削除方法はStudio NaoJun Integrationsのプライバシーポリシーをご確認ください。

利用に関する質問やデータ削除・アクセス権取消の相談はNAOJUN STUDIOSのお問い合わせフォームから受け付けます。パスワードや認証コードを送らないでください。
