Google連携のプライバシーポリシー

Studio NaoJun Integrationsが、Googleアカウントのデータをどのように扱うかを説明します。

1. 対象と運営者

本ポリシーはNAOJUN STUDIOSが運営する、業務予約とGoogleサービスを連携する内部向けアプリ「Studio NaoJun Integrations」に適用されます。一般のウェブサイト閲覧者の情報についてはサイト共通のプライバシーポリシーをご確認ください。

2. アクセスするGoogleデータ

所有者がGoogle OAuthで同意した場合に、以下の権限を利用します。

  • Gmailの読み取り（gmail.readonly）：EX予約・エクスプレス予約に関係するメールを検索し、件名、送信元、受信日時、本文から予約番号、乗車日、発着駅、列車名、座席、予約変更・取消の情報を抽出します。Gmailへの送信、メールの削除、ラベル変更は行いません。
  • Google Calendarの予定管理（calendar.events）：所有者が指定したカレンダー内で予約予定を検索・登録・更新し、予約が取り消された場合に該当する予定を削除します。既存の予定がある場合は識別子と日時を照合し、重複登録を避けます。

Gmail APIの権限上はメール全体の読み取りが可能ですが、このアプリは予約情報の同期に必要なメールを検索・処理する目的に限定して利用します。将来新しいGoogleサービスや利用目的を追加する場合は、このポリシーを更新し、必要な権限を別途求めます。

3. 利用目的・保存するデータ

EX予約の乗車予定を指定のGoogle Calendarへ反映し、同じ予約の二重登録や変更の取りこぼしを防ぐために利用します。WorkStylingの施設予約については、その予約サービスから取得した日時、場所、部屋、予約識別子を同じカレンダーに同期します。WorkStylingの予約申込みは別のWindowsプログラムが行い、Google APIを利用する同期機能そのものが予約申込みを行うわけではありません。

Windows内のアプリケーション領域には、予約識別子、予約日時・区間・列車・座席または施設名・部屋名、CalendarイベントID、処理済みメールID、同期日時、処理結果やエラーの一部を保存します。メール本文全体やGmailの受信箱を同期履歴として保存する設計ではありません。

4. 保存場所と保護

同期プログラムは所有者が管理するWindows環境で動きます。GoogleのOAuth更新トークンと別プログラムが利用するWorkStylingのログイン認証情報は、WindowsのDPAPIで暗号化して保管します。認証情報の保存先ファイルへのアクセス権限も制限します。予約情報と同期履歴はローカルに保存し、予約予定は所有者が指定したGoogle Calendarに保存されます。管理画面は一般公開せず、認証された管理環境から利用します。

5. 第三者提供・広告・AI学習

Googleユーザーデータを広告配信、広告ターゲティング、データ販売、運営者自身または第三者による汎用的なAI・機械学習モデルの開発・改善・学習に利用しません。予約の同期に必要なGoogle APIを通じてGoogleサービスに情報を反映する場合を除き、取得したGmailデータを外部の企業やサービスへ提供しません。

所有者本人を除き、人がGmailデータを閲覧することはありません。例外は、所有者の明示的な同意がある場合、セキュリティ上の調査、法令遵守のために必要な場合に限ります。内部運用に必要な分析は集計・匿名化した情報の範囲で行います。

Google APIから受け取る情報の取り扱いはGoogle API Services User Data Policy（Limited Use要件を含む）に従います。

6. 保存期間・削除・アクセス権の取消

予約と同期識別子は、重複防止・変更照合・運用記録に必要な間、所有者が管理するWindowsおよびGoogle Calendarに保持します。現時点ではすべての予約情報を一定期間後に自動削除する仕様ではありません。処理済みメールIDの記録件数と詳細な処理履歴には上限を設けています。

利用者はGoogleアカウントの接続済みアプリの管理画面からアクセス許可を取り消せます。取り消し後は新しい同期を行えませんが、既にGoogle Calendarに登録された予定やWindowsに保存された履歴は自動で全削除されません。これらの削除を希望する場合は運営者にご連絡ください。

7. お問い合わせ・改定

Googleデータの取り扱い、権限の取消、保存データの削除に関するお問い合わせはNAOJUN STUDIOSお問い合わせフォームをご利用ください。認証コード、パスワード、秘密鍵などは送信しないでください。本ポリシーを変更する場合はこのページに改定内容を反映します。
