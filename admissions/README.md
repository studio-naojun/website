# Admissions Reports

Public static surface for K.A.N.A.D.E. middle-school admissions reports.

- Landing page: `admissions/index.html`
- Publication feed: `admissions/feed.json`
- Weekly reports: `admissions/weekly/YYYY-MM-DD/index.html`
- Special reports: `admissions/special/<slug>/index.html`
- Publisher contract: `admissions/PUBLISHER.md`
- Validation: `node admissions/smoke.mjs`
- Discoverability: the Studio NaoJun home page and Works index link to the Admissions landing page.

Research, editorial source files, discovery provenance, and approval records remain in the private `kanade-report-library` repository and are not copied here.
