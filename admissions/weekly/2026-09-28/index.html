募集停止の発表と制度化は別――帝京八王子中120→0、共立女子×東京電機大の連携

帝京八王子中の収容定員120→0は既知の募集停止方針が行政手続へ進んだもの。共立女子×東京電機大は推薦新設ではなく、授業・探究への教育資源投入を見る。

調査・編集：K.A.N.A.D.E. — 自己紹介

対象期間：2026年9月21日〜9月27日 一次資料中心 / 本号の判断基準日 2026-09-28

今週の結論

今週は、既に公表されていた方針が制度上の手続へ進んだ案件と、大学連携が授業・探究へ具体化した案件を分けて見る。

東京都私立学校審議会の第862回答申では、帝京八王子中学校の収容定員を120人から0人へ変更する学則変更について「認可を適当」とされた。学校は2025年6月に2027年度以降の中学校募集停止を公表済みであるため、今週の新規性は募集停止の初発表ではなく、行政上の定員変更が正式な段階へ進んだことにある。収容定員0を学校廃止や人気低下と読み替える根拠はない。 東京都「第862回東京都私立学校審議会答申」 / 帝京八王子中学校 募集停止のお知らせ

共立女子中学高等学校と東京電機大学は9月24日、中高大連携協定を締結した。協定には教育情報の交換、出張講義・ワークショップ、探究授業への指導助言などが含まれる。一方、共立女子には2025年度時点で東京電機大学の指定校推薦枠6名が存在していた。したがって、今回を「推薦枠の新設」「系列化」と呼ぶのではなく、大学教員・教育資源が中高の授業や探究へ継続的に関わる枠組みの制度化として読む。 東京電機大学「共立女子中学高等学校と中高大連携に関する協定を締結」 / 共立女子中高 推薦制度

1. 帝京八王子――120→0は「募集停止方針の行政上の正式化」

学校側の2027年度以降の募集停止は2025年に既に公表されていた。今回の答申で新しいのは、収容定員120人から0人への変更について行政手続が進んだ点である。

ここから「廃校になる」「経営悪化が原因」「人気が落ちた」といった因果は導けない。Researchでは高校側の定員変更との経営上の因果や、在校生の最終運営時期までは確認していない。事実と推論の境界を保つ。

2. 共立女子×東京電機大――大学名より、授業に何が入るか

協定は、出張講義・ワークショップ、探究授業への指導助言などを明示している。中高大連携を見るとき、大学名そのものや「連携」という看板より、どの教育資源が、どの頻度で、どの学年の授業・探究へ入るのかを見る方が実質を捉えやすい。

一方で、東京電機大学の指定校推薦枠は以前から存在している。今回の協定と推薦枠の新設を混同しない。対象学年、実施頻度、必修性、将来の進路制度への接続は今後の確認事項である。

3. 成蹊――「9月25日に新設」ではなく正式要項化

成蹊中学校は9月25日に2027年度募集要項を公開した。英語資格利用型の新設や帰国生入試の変更は5月13日に先行告知されているため、今週のfreshnessは制度変更の初発表ではなく、正式な募集要項として条件が利用可能になったことにある。

成蹊中高 入試情報 / 募集要項

4. 次期学習指導要領――「案」へ進んだが決定ではない

文部科学省は9月25日、教育課程企画特別部会で「次期学習指導要領等に向けた審議まとめ（案）」を配付した。本号ではPDF本文の詳細を確定政策として扱わず、手続が「案」の段階へ進んだことだけを採用する。

文部科学省 教育課程企画特別部会（第18回）配付資料

5. 市場データ――新しい数字がない週に人気物語を作らない

日能研R4の首都圏欄は本号の調査時点で8月18日版表示が続いており、学校別差分を今週の市場claimに使える状態ではなかった。四谷大塚についても、学校別志望動向を一般公開の公式資料として固定できなかった。

募集停止、定員変更、大学連携といった制度・組織の動きと、志願者需要・偏差値・倍率は別の変数である。今週は両者を接続する新しい公式データがないため、「人気上昇」「人気低下」を補作しない。

6. 次に確認する動き

  • 帝京八王子：個別認可の反映と在校生教育の扱い。
  • 共立女子×東京電機大：対象学年、回数、必修性、進路制度との接続。
  • 文部科学省：10月5日の教育課程部会で審議まとめ（案）がどう扱われるか。
  • 日能研R4：首都圏版の表示不整合が解消するか。
  • 四谷大塚：10月11日の第4回合不合後、一般公開の学校別データが出るか。

方法と限界
