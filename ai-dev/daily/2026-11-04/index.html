本日の優先対応：PyPI pyprig の悪性版（該当環境だけP1）

GitHub Advisory Databaseは2026年11月3日、PyPIパッケージpyprig 1.2.0、1.2.1、1.2.2をMalwareとして掲載しました。修正版の記載はありません。OpenSSFが登録した調査では、正規のPydanticに似せたコードに、モデル初期化時にリモートコードを取得して実行する仕組みが付加されていました。解析時点で遠隔側はプレースホルダーだったと明記されており、全導入者に対して情報窃取が実際に成立したという証拠ではありません。

該当条件： pyprigの上記3版を実際に導入した開発ホスト、CI環境など。正規のpydanticを使っているだけ、あるいは名称が近いだけでは、この特定の警告に自動的に該当しません。

安全な確認・対応： 疑わしいPython環境では試しにimportやモデル生成を行わず、別の信頼できる環境から依存manifest、lockfile、SBOM、CIのインストール履歴を読んで名前・版・導入事実を照合します。該当すれば状況に応じて隔離・証拠保全、アクセスし得た秘密の見直し、必要な資格情報の別環境からの失効・再発行、クリーンな環境での再構築を実施します。復旧後は正常な配布元・依存バージョン・CI・不要な外部通信のないことを確認し、悪性版に戻すロールバックは避けます。単にアンインストールしただけで完全な復旧とは扱いません。

一次情報：GitHub Advisory GHSA-25jm-3g7h-jgf6（11月3日公表、11月4日07時台JST確認）。

MetalamaのVisual Studio拡張：同一ユーザー内のデシリアライズ問題（P2）

CVE-2026-62848は、Windows上でMetalamaのVisual Studio統合が使うnamed pipeの処理で、型の制限がなく任意の.NET型をインスタンス化できる問題です。攻撃にはすでに同じWindowsログオンユーザーで動作できる別プロセスが必要で、ベンダーは権限境界をまたぐ脆弱性ではないと説明しています。コマンドラインやMSBuildだけで構築しておりVisual Studio連携を使用しない場合は、今回のnamed pipe経路に該当しません。CVSSのHigh表記だけでインターネット経由の遠隔侵入と判断しないでください。

修正と確認： Metalama.Frameworkは利用系列に合わせて2025.1.18／2026.0.25／2026.1.19の修正版を確認。維持されているMetalama + PostSharp Visual Studio拡張は2026.1.5へ更新し、廃止済みMetalama／Caravela拡張は削除または移行します。更新前にプロジェクト設定とVS拡張の版・使用状況、復旧手段を確認し、更新後にVSの起動・CodeLens・解析とビルドが正常であることを検証します。疑わしい同一ユーザー侵害がある場合はアップデートだけで侵害を除去したと判断しません。

公表の違い： 開発元Advisoryの初報は6月27日、GitHub Advisory Databaseの公開・更新は11月3日です。11月3日に実悪用が始まったという意味ではありません。一次情報：Metalama開発元Security Advisory ／ GHSA-h26j-4vp7-x9w2（11月4日07時台JST確認）。

GitHub CodeQL 2.27.3：Python 3.15対応と独自Queryへの注意（P2）

GitHubは11月3日にCodeQL 2.27.3を公開。Python 3.15の構文・builtinへの対応、データ拡張のJSON形式、C23 _BitInt(N)などを追加しました。LLM生成データ向けai threat modelはopt-inであり、組み込みsource modelはありません。

独自のGitHub Actions向けCodeQL queryを保守する場合、Control Flow Graphの共通ライブラリ移行と旧Completionクラス削除がbreaking changeとなる場合があります。該当者は利用中のカスタムQueryを検査・必要なら修正し、従来と同じ警告を検出する回帰テストを行ってください。GitHub.comのcode scanningは自動導入、GHES 3.24への収録は将来予定です。通常のGitHub Actionsが全体で停止したという報告ではありません。

一次情報：GitHub Changelog — CodeQL 2.27.3（11月3日公表、11月4日07時台JST確認）。

DependabotがPython 3.15をサポート（P2）

GitHubは11月3日、DependabotがPython 3.15への依存更新に対応したと発表しました。github.comの全利用者が対象で、GitHub Enterprise Serverでは3.24に含まれる予定です。Python 3.15への強制移行ではなく、既存版のPythonを利用する開発者に直ちに操作は必要ありません。移行予定のプロジェクトのみ、対応する依存・lockfile・CIの実行環境とテストを確認してください。

一次情報：GitHub Changelog — Dependabot Python 3.15（11月3日公表、11月4日07時台JST確認）。

確認した範囲と留保

この調査では上記の公式AdvisoryおよびGitHub Changelogを確認しましたが、すべてのベンダー、CISA KEV全件、実際の侵害件数、個別端末の導入状況を調べ尽くしたものではありません。したがって未掲載の緊急事象が存在しないと断定しません。P0（実悪用等で即時対処）、P1（該当条件下の重大影響）、P2（重要運用変更）を区別しています。
