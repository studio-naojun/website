npm @ethersphere/bee-js 13.3.0：悪性パッケージ警告（P1）

GitHub Advisoryは13.3.0をMalwareとして登録し、導入または実行されたコンピュータを侵害を前提に扱い、別の安全な端末から秘密鍵・トークンを交換するよう強く勧告しています。 一次情報：GHSA-hh7j-5m3j-23pf（公開 2026-11-09 10:25 JST）。対象版：13.3.0。

該当条件： この正確なnpmパッケージ名と13.3.0に依存した端末・CIが対象です。他の版への影響や、各端末での攻撃成功まではこの発表だけで断定しません。

安全な確認： package-lock.jsonなどの解決済み依存版、npm ls、SBOM、CIのインストール記録を安全な環境で確認。疑わしいコードを実行しないでください。

対処と復旧： 該当版を使った実行環境は隔離・保全、別の清浄な端末から認証情報をローテーション、影響確認後に信頼できる依存とイメージで再構築します。単に削除するだけで完全駆除したとは扱いません。

留保： Advisoryは修正版・侵害件数を示していません。個別環境の感染成立は別途ログで判定します。

PyPI parseyaml 1.2.0：YAML loaderを装う遠隔コード処理（P1）

OpenSSF出典のAdvisoryでは、YAML処理ライブラリを装った依存に、外部スクリプトを取得して実行する仕組みが含まれると説明されています。解析時には実体がstubだったとの留保があります。 一次情報：GHSA-c4fv-65c3-6g99（公開 2026-11-09 09:30 JST）。対象版：1.2.0。

該当条件： 正確な配布名parseyamlの1.2.0を導入し、不審なloader経路が実行された場合の評価が必要です。一般的なPyYAMLを使うだけでは該当しません。

安全な確認： requirements・lockfile、pip導入履歴、CI/アプリのimport経路を安全な隔離環境から確認します。実行テストは行いません。

対処と復旧： 該当版を除去し信頼できる依存に置き換えて再構築。実行が確認された環境ではログ保全、影響した資格情報の交換、再開前の依存再確認を行います。

留保： 解析時のstubの状態と全配布物の挙動を混同せず、修正版と実被害の規模は未確認です。

調査範囲と非該当

確認済みは上記のGitHub Advisory原本と記載された版・条件です。全GitHub Advisory、全CISA KEV、全開発環境への該当を網羅したものではありません。特定の家族・事業・Windows端末が当該版を導入した事実は確認していません。
