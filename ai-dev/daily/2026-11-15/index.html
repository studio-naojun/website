SRP認証を使うCyrus SASLサーバーと、別製品のUnrealIRCd Webpanelについて、公式に確認できた影響範囲と修正手段を整理します。いずれも該当ソフトウェア・設定に限った問題です。一般的なPCやAI開発環境が感染していることを意味しません。

P1｜Cyrus SASL 2.1.28以前のSRP認証でバイパス可能性（CVE-2026-129483）

発表と条件： GitHub Advisory Databaseの11月15日公開情報には、Cyrus SASLの2.1.28までの版でSRP（Secure Remote Password）サーバー認証メカニズムを実際に使用する場合に認証検証の不備があると記載されています。ネットワーク上の未認証接続者が既存ユーザーとして認証され得るため、SRPを用いる認証サービスには重大な条件付き影響があります。一方、SRP機構を使わないサーバーへ同じ脆弱性が成立するとは判断できません。

重大性と未確認事項： AdvisoryのCVSS 4.0はCritical 9.3ですが、これは条件を満たす場合の技術的重大性であり、実際の悪用が確認されたことではありません。GitHubのAdvisoryはunreviewedで、構造化されたpatched versions欄はUnknown。上流にはissue #896と修正コミットへの参照がありますが、その存在だけから利用可能な修正済みリリース番号を断定しません。

安全な確認と対応： 利用している認証サービスの設定、SRPサーバーmechanismの有効・無効、実際のライブラリ/配布パッケージ版、OSディストリビューションのセキュリティ更新情報を読み取りで確認します。SRP利用が確認されたら、サービス影響・代替認証の検証を経てSRPを一時的に無効化するか、ベンダー・配布元が修正済みと示すパッケージへ更新してください。既存ユーザーの認証動作で適用を確認し、攻撃ペイロードで検証しないでください。変更前に認証障害時の復旧手順を確保します。

P1｜UnrealIRCd Webpanel：security release 1.1.1へ更新

対象と公式発表： UnrealIRCd開発者の11月14日公式案内は、管理用Webpanelという別製品にセキュリティ更新があると説明し、利用者に1.1.1へ更新するよう勧告しています。前号のUnrealIRCdサーバー本体のCVE-2026-114713とは別件です。

問題と版の違い： 1.1の元のsecurity releaseではIRC由来データの表示に関するXSS、CSRFや権限関連の修正がありました。しかし、1.1は修正が不十分な状態で公開され、1.1.1でAPIへの異なるサイトからの要求の拒否、旧アカウント権限の互換、サンプルログインの拒否、編集ファイルへのアクセス制限等を補完しています。1.1だけで対処完了とは扱いません。インストールしていない環境への影響を推測せず、実悪用済みとも断定しません。

更新・検収： 管理者はインストール済みWebpanelの版を確認し、設定・データを保全してから公式リリース1.1.1へ更新します。更新後、正規管理者でのログイン・必要なロール権限・API動作を安全な通常操作で確認してください。UnrealIRCd daemonの更新だけではWebpanelの修正を代替できません。影響があれば設定を復元し、ベンダーの修正版へ再更新できるようバックアップを保持します。

既報・確認範囲

11月13日にCISA KEVへ追加された実悪用確認済みUnrealIRCdサーバー本体とCheck Pointの2件は11月14日号で説明済みです。本号の2件には同じ実悪用認定を転用しません。CISA KEV全件や各配布元の修正状況、端末上の導入状態までは監査しておらず、新規P0が存在しないと断定しません。
