対象日：2026年11月17日／一次情報確認：2026-11-17 07:01 JST。 悪性npmとLangGraph.jsの安全情報に加え、Kubeshark MCPの条件付き権限侵害リスクと修正版v53.4.0を13時追補。 重大度は利用条件で判定し、端末・アカウントへの影響を見出しだけで推測しません。

P1｜npm @univerjs-pro/sheets-pivot-chartの2版にMalware警告

GitHubの一次情報： GHSA-h6jf-g8cj-x4v3はnpm @univerjs-pro/sheets-pivot-chart の 1.5.0と1.5.1 をMalwareとして登録。2026年11月16日00:14 UTCに公開、同日05:44 UTCに更新されました。修正版は提示されていません。古い検索結果には1.5.0だけが表示されますが、11月17日確認の公式REST APIには2つの版が掲載されています。

影響する条件： 指定配布名・版がlockfile、推移的依存、実際のインストール、CIコンテナにある場合は調査対象です。類似の名前を見た、またはアラートを読んだだけで侵害を証明できません。ただしAdvisoryはインストール・実行した機器を侵害された可能性のあるものとして扱い、すべての秘密・鍵の交換を求めています。個別の侵入経路や実被害は未確認です。

安全な確認・対処： 信頼できる端末でlockfileとnpm ls、SBOM、ビルドの履歴・CIキャッシュを読み取りで照合。導入済みなら隔離し、別の安全な端末で利用済み資格情報を失効・再発行し、クリーンな依存環境を構築。削除だけで感染除去を保証しないと公式が警告しています。再構築後に依存版、秘密の失効、ビルドとCIを検証し、該当悪性版へのrollbackを避けます。

P1｜npm pmhq-dist-win-x64 9.0.2にMalware警告

公表事実： 2026年11月16日00:12:56 UTCのGHSA-xxrh-88wg-7qf4はnpm pmhq-dist-win-x64 の 9.0.2 をMalwareとしています。公式Advisoryに修正版はありません。別版まで一律に悪性と断定できる根拠は示されていません。

調査条件・復旧： Windows向けという配布名だけから個人PCへの導入を推定しません。ロックファイル、npm ls、CI・コンテナ依存を信頼できる環境から調べ、該当版が存在した場合は隔離、別端末での秘密・トークン失効と再発行、クリーン再構築、正常な依存版とCIの再検証を行います。導入が未確認なら悪性コードを試して確認せず、追加のインストールを避けます。

P1（条件付き）｜LangGraph.js MongoDBStoreの問い合わせ式注入

公式保守元のAdvisory： 2026年11月16日13:34:22 UTC公開のGHSA-p874-xggm-73rvはnpm @langchain/langgraph-checkpoint-mongodb の 1.3.0以上1.5.1未満 を影響範囲とし、1.5.1 で修正済みとします。GHSA severityはModerateですが、共有テナント間の情報境界に影響する条件が成立した場合に限り本誌では運用上のP1とします。

必要条件・影響： 呼び出し元が制御する値を適切に検証せずMongoDBStoreのstore操作へ渡し、共有・マルチテナントstoreで実行すると、値がMongoDB問い合わせ式として解釈され、異なるnamespaceのデータが取得され得ます。DBでserver-side JavaScriptが有効ならその実行可能性にも公式が言及します。単一テナントや入力が適切に制限された利用まで被害と断定しません。実悪用の確認は本Advisoryにありません。

修正・検収： 依存版と入力経路を読み取り確認して1.5.1以降に更新し、代表的なテナント境界テスト・デプロイと依存ロックを確認。更新できない場合はstore操作前のユーザー制御値をプレーンな文字列・数値に制限。テスト用データだけで確認し、実データの越境試行や脆弱版へのrollbackを行いません。

P1（条件付き）｜Kubeshark MCPの引数注入とクラスタ侵害リスク

公表・修正版： Kubeshark公式GHSA-8vf2-hxg5-crqhは、2026年11月16日22:17:32 UTC（17日07:17 JST）にMCPツール§start_kubeshark§の引数注入を公表。Kubeshark CLI v53.1.0以上v53.4.0未満が対象、v53.4.0で修正済み。§pod_regex§がoptionとして解釈され、Helm設定の上書きにつながる問題です。

成立条件・実際の影響： §kubeshark mcp --allow-destructive§を明示的に使用し、そのホストがprivileged DaemonSetを配備できるKubernetes認証情報を持ち、エージェントが攻撃者の影響を受けた内容をMCP引数に取り込む場合、意図しないイメージ配備からクラスタ管理者権限に達し得ます。通常モードでは§start_kubeshark§は登録されません。重大度Highの公式評価ですが、全利用者への侵害や実悪用を示すものではありません。

修正と安全な確認： CLIの起動引数、版、kubeconfig権限を読み取りで点検し、v53.4.0以降へ更新。必要がなければ§--allow-destructive§を有効にせず、未信頼のエージェント入力を遮断し、MCPホストの権限を最小化します。更新後にCLI版と許可ツール・正規配備履歴を確認。攻撃用引数や悪性イメージの再現は行わず、脆弱版への巻戻しを避けます。

同時公表の別件（条件付きP2）： 公式GHSA-gj7r-p794-hhq5は2026年11月16日22:18:58 UTCに、同じ版範囲のMCP§download_file§に書込先制限の不備があると公表しました。こちらは通常のMCP起動でも使用可能で、実行ユーザーが書けるローカルファイルや、Hub認証が無効な構成でのトラフィック情報が対象です。v53.4.0に更新し、更新前は低権限ユーザーと隔離した作業ディレクトリ、Hub認証・保存先制限を確認します。確認：2026-11-17 13:06 JST。両件とも実被害・実悪用は未確認です。

P2｜GitHub AI Scanは最大20リポジトリを一括起動可能に

GitHubの11月16日公式Changelog によると、組織のcode scanning画面などから最大20件のrepositoryでAI Scanを一括開始できるようになりました。default branchを対象とするpublic previewで、結果は既存code scanning backlogに入ります。GitHub.comとGitHub Enterprise Cloud with data residencyが対象で、Copilotライセンスは必須ではありません。

費用・条件： GitHubの10月28日の公式提供・課金説明では、AI ScanはCode Security AI creditsを消費し、個人public repositoryでも請求先が生じ得ます。組織のprivate/internal repositoryではCode SecurityまたはAdvanced Security等の利用条件があります。追加費用の承認なしにscanを起動・機能を有効化せず、既存設定と過去のalertsを読み取り確認するにとどめます。
