P2｜GitHub Copilotの6モデルは12月14日に廃止予定

GitHub公式2026年11月13日発表を11月19日07時台JSTに再確認。2026年12月14日にCopilot Chat、inline edits、ask/agent mode、code completionsを含むCopilotの体験で次の6モデルを廃止予定です。Copilot以外の提供元APIが同日終了する発表ではありません。

対象と公式推奨先： Claude Fable 5→Claude Fable 5.2、Claude Haiku 4.5→Claude Haiku 5.5、Gemini 3.8 Flash→Gemini 4 Hydrogen、Gemini 4 Argon→Gemini 4 Carbon、Grok 4.6→Grok 4.7、Kimi K3→代替未発表（公式を11月19日に再確認）。既刊のモデル表は公式と一致しており、実在名や推奨先を推測変更しません。

公式の例外： Claude Haiku 4.5に限り、個人GitHub Copilotの年額契約者には廃止が適用されないとGitHubは明記。他のモデルや全契約者を一律に例外と扱いません。Business/Enterpriseでは組織のモデルポリシーと代替モデルが現在許可されるかを個別確認します。

安全な確認・切替： 12月14日までに対象のモデル設定と実際のワークフローを読み取り比較し、既存テストで代替を検証します。廃止後に元の廃止対象モデルへ戻すことはできないため、期限後は許可済みの別のサポート中モデルか従来の開発手順を復旧先にします。権限・課金・契約を自動変更しません。

P2｜GitHub-hosted ActionsのARM32ジョブ実行は12月8日までに終了予定

GitHub公式2026年11月12日発表は、GitHub Actions hosted runnersのWindows/LinuxにおけるARM32ジョブ実行を2026年12月8日までに終了予定と明記。Node.js 20終了とNode.js 24のARM32非対応に伴い、hosted runnerでのnative AArch32 user-space実行のサポートが終了します。

対象範囲は公式のGitHub-hostedが正確です。 既存Claudeレビューはself-hostedに影響する可能性を指摘しましたが、一次公告はhosted runnersを明記しており、対象をself-hostedへ逆転させる根拠はありません。ただしself-hosted ARM32の個別サポート期限は、この公告だけでは断定しません。ARM64やx64全体の終了でもありません。

workflowのrunner OS/CPUアーキテクチャと実際にARM32/AArch32を使うジョブを読み取りで照合し、必要なものだけARM64/x64またはサポートされるrunnerへ移行テスト。既知良好なビルドの復旧方法と期限後のCI結果を検収します。

P2｜GitHub Code Security AI ScanのREST管理プレビュー、creditsとPR設定を分離

GitHub公式2026年11月13日発表を11月19日07時台に再確認。organization/repository向けのAI Scan for repositories設定（repository_scan）をGET/PATCHで管理するpublic previewです。既存のAI Scan for pull requests設定（pr_scan）と同じ要求で変更できます。

HTTP 422とポリシー： enterprise policyがAI Scanを禁止する場合は有効化がHTTP 422で拒否され、同一リクエストのrepository_scanまたはpr_scanのどちらかが拒否された場合は両設定とも変更されません。これはGitHub公式説明に明記されており、当初記事の記述は正しかった点です。organization無効時はrepository側で有効化できず、organization有効時は個別repositoryでopt out可能です。

費用条件： repository_scanをenabledにしただけではオンデマンドのrepository scanは開始しませんが、実際にユーザーが実行する各scanはGitHub Code Security AI creditsを消費します。別設定のpr_scanについて、今回の公告だけからPR契機の自動実行がない・無料であるとは断定しません。自動PRスキャン条件とcredit発生は該当REST docs/課金条件を別に確認してください。

対象と安全な確認： organization-owned public repositoriesと、GitHub Code SecurityまたはGitHub Advanced Security契約があるprivate/internal repositories。GitHub Enterprise Serverは対象外。今回、有料スキャンの実行、PATCH、権限や契約の変更はせず、利用条件の照合に限定します。

既報との違い・未確認の範囲

11月9日Google公告で実悪用が言及されたChrome CVE-2026-125350は11月11日号で既報。Chrome Stable 157の83修正とCritical 5件も11月12日号で扱っています。本号の3件はそれらとは別の運用予告・管理機能です。CISA KEV/NVDや主要ベンダーの全件照合、個別開発環境のモデル・runner・料金状態は確認していないため、新しいP0の不存在や個別環境への非該当を保証しません。
