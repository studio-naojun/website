P2｜Copilotの6モデルが12月14日に廃止予定

発表・対象： GitHub公式11/13 Changelogによると、2026年12月14日にGitHub Copilot Chat、inline edits、ask/agent mode、コード補完などから6つのモデルを廃止する予定です。Copilot以外のモデル提供元のAPI停止と混同しません。

対象と移行候補： Claude Fable 5 → Claude Fable 5.2、Claude Haiku 4.5 → Claude Haiku 5.5、Gemini 3.8 Flash → Gemini 4 Hydrogen、Gemini 4 Argon → Gemini 4 Carbon、Grok 4.6 → Grok 4.7、Kimi K3 → 代替は未発表（11月13日時点）。例外： Claude Haiku 4.5を利用する年額の個人GitHub Copilot契約者には、この廃止は適用されないと公式に記載されています。

安全な確認と対応： Copilotの選択モデル、各自が明示したエージェント設定、管理者モデルポリシーを読み取りで確認し、対象モデルだけ切替計画を作ります。Enterprise/Businessのデフォルト有効化を止めている組織では、代替モデルが許可済みか確認する必要があります。実際に移行する場合は現行のテストケースで成果品質や動作を比較し、問題が出ればサポート中の元のモデル・手順へ戻します。追加契約・モデル許可の拡大を前提としません。

P2｜GitHub-hosted ActionsのARM32が12月8日までに終了予定

発表・対象： GitHub公式11/12 Changelogは、GitHub-hosted runner上のWindows/Linuxで、ARM32（AArch32 user-space）のジョブ実行サポートを2026年12月8日までに終了すると予告。Node.js 20サポート終了およびNode.js 24のARM32非対応に関連する変更です。ARM64やx64のすべてのジョブを停止するものではありません。

確認・緩和： workflow定義と既存jobログからrunner OS・CPUアーキテクチャ・ARM32バイナリのネイティブ実行の有無を確認。該当する場合は代替runner・ARM64/x64への移行でテストを先に通し、依存ライブラリ互換性を見ます。self-hosted runnerの具体的な挙動はこの公告だけから断定しません。移行時は既知良好な構成へ戻す手順を残し、期限後のworkflow失敗を監視します。

P2｜AI ScanのREST管理APIはプレビュー、利用には credits 注意

発表・条件： GitHub公式11/13 Changelogは、Code Security AI Scan for repositoriesにorganization/repository REST API管理のpublic previewを追加。既存のorg/repoのAI Scan GET/PATCHエンドポイントでrepository_scanをenabled/disabledに設定でき、pr_scanと同時に更新できます。

ポリシーと費用： organizationで無効化した場合、下位repoは独自に有効化できません。Enterpriseポリシーが禁じる場合や同時変更の一部が拒否される場合はHTTP 422となり両設定が更新されません。対象は組織所有のpublic repositories等と適切なCode Security / Advanced Security契約があるprivate/internal repositories。GitHub Enterprise Serverは対象外です。設定をenabledにしてもscanは自動起動しませんが、ユーザーが実行するscanはGitHub Code Security AI creditsを消費します。

安全な確認： 許可済みread-only API/UIで現在のポリシー・利用権限・credits条件を確認するだけにとどめます。本号の調査では、有料スキャン、PATCHによる変更、権限変更、新規契約を実施・推奨していません。既存の静的解析・レビュー機能を廃止する根拠とも扱いません。

既報との違い・未確認の範囲

11月9日Google公告で実悪用が言及されたChrome CVE-2026-125350は11月11日号で既報。Chrome Stable 157の83修正とCritical 5件も11月12日号で扱っています。本号の3件はそれらとは別の運用予告・管理機能です。CISA KEV/NVDや主要ベンダーの全件照合、個別開発環境のモデル・runner・料金状態は確認していないため、新しいP0の不存在や個別環境への非該当を保証しません。
