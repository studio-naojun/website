AI開発・セキュリティ日報｜2026年10月30日号

AWS LambdaのBrotli修正Phase 2の予定と実効確認、GitHub Copilot Fusionのローカルモデル対応、OpenAI API旧モデルの廃止準備。

調査・編集：K.A.N.A.D.E.　／　確認時点：2026-10-30 08:40 JST

調査時点：2026年10月30日朝 JST。 昨日の重要情報を「今日発生した事故」と誤記しません。情報の優先度は影響条件付きです。

本日の優先対応

  • P1：AWS Lambda上でBrotli圧縮入力を扱う関数。 AWSがNode.js向け更新のPhase 2開始日として10月30日を示しています。予定日だけで適用済みと判断せず、cold-startのruntime patch版を実測してください。
  • P2：GitHub Copilot Fusionのローカルモデル振り分けと費用の確認。 10月28日公開の新機能は10月30日の運用判断に影響します。ローカルモデルを選べてもクラウド通信が不要になるわけではありません。
  • P2：OpenAI APIで旧モデルを固定している開発者。 2027年1月・4月の廃止予定をdependency/設定から点検してください。これは10月30日発生の障害ではありません。

1. AWS Lambda：Brotli修正版の段階配布と実効確認（P1）

何が起きたか。 Brotli decoderの CVE-2026-111497 に対してAWSは10月28日15:00 PDT（10月29日07:00 JST）にSecurity Bulletin 2026-155-AWSを発表、10月29日14:00 PDT（10月30日06:00 JST）に更新した。2026年10月30日は、Node.js 22/24/26のZIPランタイムで自動更新Phase 2を予定している日。ただし各AWSリージョンへの配信完了時刻は確約されていない。

影響対象・非該当条件。 Lambdaの影響するNode.js/.NETランタイムで、攻撃者由来Brotli圧縮入力を展開する関数。Lambda管理基盤サービスそのものは対象外とAWSは明記。Python/Ruby/OS-only provided.al2023の標準ランタイムにはBrotliライブラリは含まれないが、利用者が独自にbundledした場合は別途更新が必要。

今すべき対処。 Node.js 22/24/26用Lambdaコンテナbase imageは修正済みとAWSが説明。利用者のイメージは修正済みbaseで再ビルド・再デプロイする。ZIP形式はPhase 1が完了し、コードまたは設定を実際に更新すると修正runtimeを取り込める。設定値を変更しない「zero-change」再実行は十分ではない。Auto runtime update modeはPhase 2配布を確認する。Node.js 18/20等のサポート終了runtimeにはこのセキュリティ更新が届かないため、サポート対象へ移行する。

確認・rollback。 CloudWatchのcold start INIT_START行に、Node 22は nodejs:22.mainline.v157以上、Node 24は nodejs:24.mainline.v114以上と表示されるか確認。Node 24はprocess.versionだけではBrotli修正版の適用を判断できない。更新後に正常圧縮データの処理を確認。問題が出た場合も旧脆弱runtimeを外部公開し続けず、入力経路制限のもと復旧する。

未解明点。 10月30日朝の各リージョン配布完了・CodeBuildイメージ配信実績は未確認。予定は完了証拠ではない。次の13時/19時枠でも公式Bulletinと関数ログを照合する。

一次情報： AWS Security Bulletin 2026-155-AWS（2026-10-28 PDT公表、10-29 PDT更新）（新しいタブ）。

2. GitHub Copilot Fusionでローカルモデルの選択が可能に（P2）

何が起きたか。 GitHubは10月28日、Copilot Fusionのモデル自動振り分け（GA）と、ローカルモデルも選択できるexperimental previewを公開。Fusion Standard/High/Maxでは状況に応じて複数モデルをルーティングする。

対象・非該当。 GitHub Copilotアプリ、CLI、VS Code等で対象機能を有効化する利用者。WindowsのWindows ML providerにはMAI Code 1.1 Flashのmanaged downloadがあり、macOS/LinuxでもCopilot CLIと互換するローカルOpenAI-compatible endpointを接続できる。Copilot appのローカル自動振り分けは現時点でWindows ML管理モデルに限定されており、macOSのBYOK設定だけで自動振り分け可能と断定できない。

影響・費用。 Fusionは利用した各モデルの標準レートに従って課金される。Paidプラン向け30%割引はGitHubが「期間限定」と案内。ローカル推論が使えてもクラウドで振り分け判断を行うため、完全オフライン動作とはならない。

今すべき対処。 Copilotを使うなら、利用プランとモデル選択、推論実行先、送信データ・費用上限を確認。CLIでexperimental modeと/modelを確認し、Windows Copilot appではSettings > Model providersのWindows ML、Settings > ExperimentsのLocal model auto routing、VS Codeではchat.copilot.localModel.enabledが提供される。未導入の人に設定変更の義務はない。

確認・rollback。 小さいテストで選択モデル、実際のcloud/local routingと課金を観測。品質が合わなければexperimental local routingを無効にして既存モデル選択へ戻す。

未解明点。 個々のPCのGPU/RAM適合とCopilotアカウントの利用権限、ローカルで選べるモデルは環境ごとに異なる。

一次情報： GitHub Copilot Fusion local models（2026-10-28）（新しいタブ）、GitHub Copilot Fusion GA・料金（2026-10-28）（新しいタブ）。

3. OpenAI API旧モデルの停止予定：計画的な移行準備（P2）

事象。 OpenAI公式Deprecationsは、2026年10月14日通知のGPT-4系列を2027年1月14日、10月1日通知のGPT-5.3-Codex/5.1等を2027年4月1日にAPIから削除予定と表示。10月30日の新規停止・障害ではない。

該当条件・非該当。 APIで明示的に gpt-4o-2024-08-06、gpt-4o-2024-11-20、gpt-4o-mini-2024-07-18、gpt-4.1-2025-04-14、gpt-4.1-mini-2025-04-14等を参照するアプリは2027年1月14日までに切り替えが必要。GPT-5.3-Codex gpt-5.3-codex等は2027年4月1日が期限。モデル名を使用しない環境には該当しない。

影響・対処。 停止予定日を過ぎるとAPIエラーやジョブ失敗が発生する可能性。まず設定・IaC・CI・永続キューで固定したmodel IDを検索し、公式の推奨後継モデルへ段階移行。機能差・料金・制限に応じてテスト環境で出力品質、ツール呼び出し、JSON schema、料金を照合する。

確認・rollback。 テスト・カナリア実行で成功率と費用を計測。停止日より前は旧モデルへ戻せるが、その停止日を越えたrollback先には使わない。期限と移行先は次回の公式更新で再確認する。

未解明点。 利用アプリ固有の互換性は未検証。公式の削除予定日は後日変更され得る。

一次情報： OpenAI API Deprecations（2026-10-30確認）（新しいタブ）。
