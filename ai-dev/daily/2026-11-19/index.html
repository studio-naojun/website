P0追補｜CISA KEVの2026年11月18日追加4件：LiteLLM、Apache Axis、REDCap、Synology

新たな確認：2026年11月19日07時台JST。 CISAのKEV公式カタログは2026.11.18版（公開11月18日19:17 UTC＝19日04:17 JST）で、4件を11月18日付で新たに登録しました。これは当該脆弱性の悪用が確認されたという意味で、すべての利用者の侵害を意味しません。昨日報告済みのPuppet Enterpriseとは別です。

LiteLLM / CVE-2026-40217：custom-code guardrailのsandboxを越えるコード実行

対象条件： Python litellm 1.81.8以上1.83.10未満でLiteLLM Proxyのcustom-code guardrailテスト機能を使う場合に、細工された利用者PythonからProxyプロセス内のコード実行につながり得ます。デフォルトではProxy管理者の認証情報が必要なAPIで、全環境が無認証で攻撃可能とはいえません。CISAは11月18日付で実悪用をKEV登録しました。関連するLiteLLM公式GHSAは2026年5月公表です。

対処・安全な確認： GHSAの修正済み版には相違があります。版範囲メタデータは1.83.10以上を修正済みとしていますが、本文は1.83.11以降へ更新するよう案内します。保守的に1.83.11以降へ更新し、公式配布元と実際のProxy版を照合してください。更新までの暫定策はテストAPIへのアクセスをreverse proxy/API gatewayで拒否すること。復旧後は正常なguardrail利用と認証・アクセスログで確認し、悪用用bytecodeは実行しません。

Apache Axis 1.x / CVE-2026-90436：SOAP Fault処理時の危険なclass読み込み

対象条件： CISAが11月18日付で実悪用を登録。旧Apache Axis 1.xで外部から受信するSOAP faultが任意のclassをロード・生成する問題。指定したclassがアプリケーションのclasspathで利用可能な場合などにRCEの条件が成立します。すべてのJavaアプリがこの旧SOAPエンジンを使うわけではありません。

対処・安全な確認： Axis 1.xは保守終了系列。依存ライブラリと実稼働のSOAPエンドポイントを読み取り確認し、サポートされるSOAPエンジンへの移行、公開到達性の制限を優先します。現行の確定した公式リリース版を今回の一次資料で確認できていないため、修正版番号を推測しません。Apache公式原本とCISAを照合し、変更後は通常の正当なSOAP要求とログで検収。危険なfaultを送らないでください。

REDCap / CVE-2026-90817 と Synology DSM・BSM / CVE-2024-10441

REDCap： CISAが11月18日付で実悪用を登録。公開surveyの有効なsurvey hashを攻撃者が知っているなど、特定のルーティングとData Importの処理条件が成立した際に、通常の管理者認証なしでRCEに至り得ます。実版・公開survey機能・インターネット到達性・公式更新通知を確認。必要な制限は研究データ収集への影響を評価して行います。修正版番号は今回直接確認できた一次CVE資料に記載されないため推測しません。

Synology： 公式Synology-SA-24:20が2024年に公表したCVE-2024-10441について、CISAが2026年11月18日に実悪用を新たに登録。DSMは製品系列で修正点が異なり、7.2.2系は7.2.2-72806-1以降、7.2.1系は7.2.1-69057-6以降、7.2系は7.2-64570-4以降、7.1系は7.1.1-42962-7以降、6.2系は6.2.4-25556-8以降を公式表と照合。BeeStation OSは1.1-65374未満がCVE記載の影響版。機器の実版、正規更新履歴と公開設定、正常なサービスを安全に確認します。未修正NAS全体を憶測で列挙しません。

期限と留保： CISAの期限はLiteLLMが2026年12月2日、その他3件は11月21日で、米国の対象連邦機関の是正基準です。民間全利用者への一律法的期限ではありません。個々の利用者やJunの端末・サーバーに該当する証拠、被害主体はありません。

P0｜正規PyPI「agent-framework」1.26.1・1.26.2に資格情報窃取コード

2026年11月18日00:31 UTC（日本時間18日09:31）公開のGitHub公式 GHSA-764m-3ppc-5m73は、Microsoft Agent Frameworkの正規配布名 agent-framework（pip/PyPI） の 1.26.1および1.26.2 をMalwareとしています。両版は17日UTCに配布され、その後PyPIから削除されました。これは似た名前の偽物ではなく、正規パッケージの特定2版に関する問題です。

成立条件・影響： 対象wheelをインストールしたPython環境には自動起動する「.pth」フックが含まれ、agent_frameworkをimportしなくてもPython起動時に処理が走り得ます。環境変数、各種トークン・資格情報ファイル、他プロセスの環境情報に加え、Azureのmanaged identityやAzure DevOps、GitHub ActionsのOIDCトークンを収集・外部送信するコードが確認されています。CI、クラウド実行環境では影響が大きくなり得ますが、実際の漏えい量、攻撃者、個別システムの侵害有無は現時点の公開Advisoryからは確定できません。

非該当条件： 同GHSAが最後のクリーン版とする 1.26.0以前 は、この2版の悪性コードを含みません。関連ライブラリの名前やMicrosoft製品を使っているというだけでは、当該wheelの導入とはいえません。

安全な確認・復旧： まずlockfile、SBOM、pip/uvのインストール履歴、CIログ、内部ミラー・wheelキャッシュで対象配布名と正確な版を照合します。対象環境内での安易な python、pipの起動は避けてください。フックを再実行しかねません。該当版が導入されていた場合は環境を隔離し、信頼できるシェル・管理経路で悪性フックとパッケージを除去し、クリーンな依存・イメージから再構築します。導入予定版は当面 agent-framework==1.26.0 に固定し、キャッシュやCIミラーに残った悪性wheelの再投入を防ぎます。さらに到達可能だった秘密・クラウド認証・CIトークンを安全な別端末から失効・再発行し、正規のビルド・動作確認を行ってください。単純なアンインストールだけで漏えい済み秘密は回収できません。危険なコードを動かす攻撃再現や、悪性wheelの再インストールは不要です。

留保： GHSAに修正済みの新しい版は指定されていません。1.26.0は既知クリーン版への固定策であり、今後のリリース全般の安全保証ではありません。発見経緯やアップロード権限の侵害原因について断定しません。個別の利用環境に本パッケージが入っているという実測もありません。

P1｜npm「@tnhorg/agent-skills」Malware：導入済みの場合のみ隔離・再構築を優先

GitHub公式 GHSA-fv82-jh67-xx7qは2026年11月18日00:24 UTC（日本時間18日09:24）に、npm @tnhorg/agent-skills をMalwareと登録しました。影響範囲はAdvisory上 全版（>=0）、修正版はありません。

成立条件と対応： 実際にこの正確なパッケージをインストールまたは実行した環境を対象に、GitHubは全面的な侵害の可能性を前提として、安全な別の端末から秘密・キーを交換し、隔離とクリーン再構築を行うよう警告しています。依存lockfile・導入記録・CI履歴で同名パッケージの有無を確認してください。削除しただけでは追加の悪性コードが残らないと保証できません。導入歴が確認できない端末や一般の「agent skills」を一括して感染扱いする根拠ではありません。更新できる修正版が指定されるまでは当該パッケージを使いません。
