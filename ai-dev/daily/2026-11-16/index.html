対象日：2026年11月16日／一次情報の確認：11月16日13時台JST。 GitHub Copilotモデルの提供終了予定日と、公開リポジトリのActionsに予定された一時ブロックを中心に、該当者が安全に確認できる運用変更を整理します。

P1｜GitHub Copilotの3モデルが11月16日に提供終了予定

対象・公表日： GitHubが2026年10月15日に発表した予定では、本日11月16日にClaude Opus 4.8、Claude Opus 5、GPT-5.6 TerraをGitHub Copilot Chat、inline edits、ask/agent mode、補完などの体験から廃止します。これはGitHub Copilot内でのモデル提供変更であり、モデル提供元の外部APIや他サービスの一律停止ではありません。13時台に各ユーザーの選択画面から実際に消えたかまでは検証していないため、「全利用者で廃止完了」とは断定しません。

代替・例外： GitHubの推奨はClaude Opus 4.8/5→Claude Opus 5.5、GPT-5.6 Terra→GPT-6.1 SolまたはGPT-6 Lunaです。Claude Opus 4.8については年額契約の個人GitHub Copilot利用者には廃止が適用されない例外を公式が明記。Business/Enterpriseの代替モデルは組織の管理ポリシーで無効の場合もあり、勝手に権限を広げないでください。

安全な確認・切替： Copilotの現在のモデル選択、コードアシスタントやエージェント定義のモデル指定、組織の許可済みモデルを読み取りで照合します。廃止対象を固定したworkflowがある場合は、権限の範囲で使用可能な推奨代替に切り替え、同じ代表タスクで出力品質・Tool利用・CI動作を比較。問題があれば現にサポートされている別モデルに戻し、既に廃止されたモデルへの強制復帰は前提にしません。契約追加やモデルの強制有効化は不要です。

P2｜GitHub Actions public repoのbrownoutは11月17日01〜03時JST予定

日時の読み替え： GitHubの11月2日公式告知にある11月16日16:00〜18:00 UTCは、日本時間11月17日01:00〜03:00です。今の11月16日13時台JSTにはまだ始まっていません。対象は既定ブロックの対象となるpublic repositoryのpull_request_targetイベント。private/internal repoとGitHub Enterprise Serverは対象外です。

何が起きるか： 該当する公開repoでは一時的にworkflowを実行せず、失敗runにannotationが付きます。恒久的な既定blockは12月2日予定。今から公開repoのActions Insightsのevaluate-mode警告とworkflow定義を確認し、通常のpull_requestなど安全な代替イベントへ移せるか検討します。allow例外はsecretsに触れるbase-repo権限でforkの未信頼コードを実行しないと証明できるworkflowにだけ狭く適用し、単にテストを通すため安全設定を外さないでください。日時が来た後、実runで成否を確認します。

P2｜GitHub secret scanningがCloudflare service tokenの検出を追加

GitHubの11月12日公式Changelogによると、新たにcloudflare_access_service_tokenを検出対象に追加しました。公開repoでpartner型の秘密を検出した場合は発行元への通知経路、user型は適切なrepository alertがあり得ます。全Cloudflare APIキーやあらゆる秘密が自動検出されるという意味ではありません。

Cloudflare Access service tokenをGitHub上で扱う運用者は、既存のsecret-scanning警告を機密文字列をコピーせずに確認。正規の秘密管理外へ誤って登録した事実が見つかれば発行元の公式手順で該当トークンを失効・再発行し、最小権限と利用サービスの復旧を検証してください。検出機能追加だけで流出・不正利用が確認されたとは判断しません。設定や課金の追加は本調査の条件に含めません。

既報と調査の限界

CISA KEVで11月13日に追加された実悪用確認済み2件は11月14日号に掲載し、11月15日号ではCyrus SASLのSRP条件付き認証バイパスとUnrealIRCd Webpanelの更新を整理済みです。本号で同じ事件を新たな悪用として重複掲載しません。CISA KEV/NVD全件、個々のCopilotモデル提供状態、各ユーザーの設定・利用端末、Actions全実行結果は網羅しておらず、最新P0不存在を断定しません。
