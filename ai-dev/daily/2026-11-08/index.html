PyPI rainbowcolors 0.1.0：Windowsで実行ファイルを取得・起動（P1）

GitHub Advisoryの解析によれば、色付き表示用と称するパッケージで、Windows上のColorメソッドを最初に呼び出すと外部ファイル共有から実行ファイルを取得・起動し、Microsoft Defenderの除外設定を試みます。 一次情報：GHSA-fh9h-99qg-6xm4（公開 2026-11-08 21:33 JST）。対象版：0.1.0。

該当条件： 対象のPythonパッケージの0.1.0を実際に導入・呼び出したWindows環境が主な確認対象です。名前の似た別ライブラリだけでは該当しません。

安全な確認： 依存関係のlockfile、pipの導入履歴、CIログと端末防御ログを安全な端末から照合します。検証のために対象パッケージをimport・起動しません。

対処と復旧： 実行が確認された環境はネットワークから分離して証拠を保全し、アクセス可能だった秘密を安全な別端末から失効・再発行してクリーンなイメージから再構築します。悪性版への巻き戻しはしません。

留保： 公式Advisoryに修正版は示されておらず、感染が成立した端末数は確認できません。

PyPI infra-libs 99.99.99：install/import時のホスト名DNS送信（P2）

公式Malware Advisoryによれば、セットアップ時とimport時にインストール元のホスト名をDNS照会に埋め込み、外部の権威DNSへ伝える実装が含まれます。 一次情報：GHSA-cj88-j9xh-9cwj（公開 2026-11-08 21:33 JST）。対象版：99.99.99。

該当条件： 正確な名前と99.99.99版をインストールまたはimportした環境が対象です。Advisoryが示す送信対象はホスト名であり、秘密鍵の流出を同じ証拠から断定できません。

安全な確認： pip freeze／ロックファイル、ビルドログ、許可されたDNS監査ログを照合。分析のために再インストールしないでください。

対処と復旧： 該当依存を除外してクリーンな環境から再ビルドし、必要に応じホスト識別子の露出を評価します。移行先で依存関係を再確認し、当該版には戻しません。

留保： 修正版の記載はなく、外部の受信者が何を利用したかは一次資料だけでは確認できません。

調査範囲と非該当

確認済みは上記のGitHub Advisory原本と記載された版・条件です。全GitHub Advisory、全CISA KEV、全開発環境への該当を網羅したものではありません。特定の家族・事業・Windows端末が当該版を導入した事実は確認していません。
