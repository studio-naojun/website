npm npm-scanner：Malware警告、同名ツールと取り違えない（P1）

GitHub Advisory Databaseが配布名npm-scannerをMalwareとして登録しました。告知はインストール済み環境の侵害を疑い、別端末から鍵をローテーションし再構築するよう勧告しています。 一次情報：GHSA-pc5x-m587-83hh（公表 2026-11-10 13:28 JST）。対象版 >=0（Advisory掲載範囲）。

条件： npmレジストリ上の正確な配布名npm-scannerを導入した環境が対象です。任意のnpm脆弱性スキャナー製品やコマンド全般が危険という意味ではありません。

安全な確認： package.json・lockfile・SBOM・CI導入履歴で配布名を完全一致で確認。安全確認のための再インストールや実行はしません。

復旧： 該当導入ホストを隔離・証拠保全し、秘密を別の清浄な端末から再発行、信頼できる依存のみで再構築します。削除だけで復旧完了とせず、導入時期・到達可能だった秘密の範囲を確認します。

未確定： 公開Advisoryには技術的な起動条件、実被害件数、修正版の情報がなく、個々の端末の感染成立は未検証です。

PyPI shanks 0.0.4：importによるIP・所在地データ送信（P2）

OpenSSFの解析を載せたGitHub Advisoryによると、shanks/shanks.pyをimportすると外部の位置情報サービスでIPアドレスと所在地を取得し、ハードコードされたDiscord Webhookへ投稿する処理が含まれます。 一次情報：GHSA-547v-q874-636x（公表 2026-11-10 09:32 JST）。対象版 0.0.4。

条件： 正確なPyPI配布名shanksの0.0.4を実際にimportした場合の情報露出が対象です。IPに基づく推定地理情報でありGPSの正確な現在地と同一ではありません。

安全な確認： requirementsとlockfile、import履歴・CIのコード経路、ネットワーク監査を安全に確認。悪性コードを検証目的で読み込まないでください。

復旧： 依存を除去して清浄な環境で再構築し、IP・所在地の外部共有の可能性を情報管理上評価します。外部投稿の範囲は利用者ごとの証拠で判断し、悪性版へ戻しません。

未確定： このAdvisoryから秘密鍵流出や遠隔操作実行まで断定できず、修正版・受信側での利用も未確認です。

対象と検証範囲

掲載した公式Advisoryは各パッケージの個別警告です。すべてのnpm/PyPI製品やJunの端末が影響を受けたことを意味しません。後追い調査時点の証拠による記事であり、既に実施された検収を作りません。
