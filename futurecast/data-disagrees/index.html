FUTURECAST / DATA DISAGREES / 2026—2027

信じられない未来を、数字で覆せるか。

多くの人が「起きない」と考える。それでもデータが示す発生確率は50%を超える。そんな歴史の転換点だけを探す、新しいFUTURECASTです。

予測を採用するには、事象の期限・数値モデル・人々の予想がすべて一致していなければなりません。現時点でこの条件を完全に立証できた予測はありません。

THE TEST / 公開条件

NOT YET / 採択しない理由

SLOW FORECAST / 予測の更新

毎日ではなく、
証拠が変わったときに。

月に一度、一次資料の更新有無を確認します。新しい数値推定と人々の予想が厳密に揃ったときだけ新規採択を検討します。採択済みの予測を変更する場合も、過去の数字は消さず履歴に追記します。
