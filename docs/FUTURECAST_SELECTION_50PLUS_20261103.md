# FUTURECAST 選定方針改訂 — DATA DISAGREES / 50+ (2026-11-03)

## ユーザーが変更した目的

従来の「まさか起きれば大事件」という *低確率・高影響* の収集を、**多数の人は起きないと思う一方、検証可能な証拠と適切な予測モデルでは発生が優勢になる *認識逆転* 型の予測**に変更する。

- 本編に採用するのは原則 **発生確率が厳密に50%超** の事象のみ。強制的に51%へ調整しない。
- 同じ命題・同じ期限を対象にした一般回答者の予測が過半数で50%未満であることを資料で示す。単に「信頼しない」「買いたくない」を代用しない。
- 実際の事象は初回固定日から原則365日以内。統計の集計発表は後日でもよいが判定資料の発行期限を事前指定。
- 民主主義の選挙結果・政治的役職者の勝敗をAI独自ランキングにしない。監査可能な制度上の事実、産業・科学・技術転換に焦点を当てる。
- 一次資料・過去実績・基準率・予測モデルを区別し、発生確率の推定方法、感度分析、最大の反証を出す。
- **未校正の主観推定と、データから算出した校正済み確率は別物。** 点推定だけでなく前提依存性を表示する。
- 事前調査が不足すれば公開候補なしでよい。件数ノルマなし。

## Astraの結論

**すべての条件を確認できた新規採用は0件。** この結論は「起こりそうな事象はない」という意味ではない。対象の出来事を「起きない」と考える人が過半数という**同一命題に対する直接の調査が未取得**であり、公開資料の「中心予測」を勝手に70%などに変換する統計的根拠もまだない。

## 認識差を調べる場合の直接設問

### 優先候補Aの数値ストレステスト（発生確率の代用品ではない）

同一データ系列のEmber 2025年値は、太陽光 **2,778 TWh**、原子力 **2,812 TWh**。差は太陽光が **34 TWh** 少ないだけである。2026年の原子力発電が前年比 **+5%** だとしても、太陽光側は **約+6.3%** 増えれば上回る。さらに原子力が **+10%** なら、太陽光は **約+11.4%** の伸びが必要。Emberによれば太陽光の年間伸び率は過去10年間、最低でも21%だった。

よって **「太陽光が2026暦年に原子力を超える」方向は、少なくともこれら2つの下振れ想定には耐える**。しかし、過去の成長率を将来の発生確率に直接読み替えたり、比較対象を別データ系列の核発電量へすり替えるのは不可。このストレステストだけから「95%」等の数値を発明しない。

根拠: https://ember-energy.org/latest-insights/global-electricity-review-2026/2025-in-review/ 、https://ember-energy.org/latest-insights/global-electricity-review-2026/electricity-demand-and-supply-trends/

「**2026年の世界の太陽光発電量は、同年の原子力発電量を上回ると思いますか。**」と、定義・期間・単位まで一致した質問を、資料とAI確率を見せる**前**に、0〜100%の確率で尋ねる。採用には、代表性ある標本で「50%未満と回答した人が過半数」という根拠が必要。Web読者の自己選択投票は読者内の参考値にとどめ、「日本人の大半」などと表現しない。

FRI LEAPには、2027年の米国無人配車の割合について専門家中央値7.3%、一般回答者中央値5%という**同じ問いでの認識差**がある。ただしこの値は事象の発生確率でなく、米国配車市場での**シェア予測**であり、今年の対象年末は365日窓外でもあるため、そのまま本編には採用しない。

- 形式的な毎日更新は不要。新しい一次資料が出たときと四半期棚卸し時だけ検討し、ユーザーが望む歴史的規模を維持。
