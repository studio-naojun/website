# NAOJUN STUDIOS design, 2026-10-04

## Direction

An independent studio making useful things for everyday life. Two intersecting ribbons
give the home page an original visual signature; the work catalogue uses individual
art direction, a restrained paper/ink/cobalt palette, and editorial typography.
Home, Works and About are rebuilt. Nine existing landing pages receive matching
navigation and footer treatment while retaining their main content and functionality.

## Verification

- Chromium and WebKit: eight routes at 360, 390, 768 and 1440 CSS pixels; no horizontal
  overflow or clipped game titles. Reviewed desktop and mobile screenshots.
- Axe WCAG 2 A/AA and 2.1 AA automated checks: zero reported violations across eight
  routes at 390 px in both engines. This is not a complete accessibility certification.
- Keyboard menu naming, Escape/focus restoration, dark-section focus contrast,
  catalogue filters, no-JavaScript access, reduced-motion, motion toggle, and actual
  absence of canvas draws while paused/offscreen verified.
- Twelve modified HTML pages: 245 local references resolve; unique IDs, one main
  heading, and image alternatives/dimensions checked.
- Existing contact, investment, admissions and discovery smoke checks pass.
- Existing analytics runtime, canonical URLs, discovery data, product sales links,
  article data and publishing workflows remain unchanged.

Review iterations corrected image distortion, small-screen type clipping, fallback
art double rendering, low-contrast secondary text and keyboard focus, and Contact's
current-page marker. WebKit required a local HTTPS server to respect the existing
contact page CSP; production CSP was not relaxed.

## Run checks

```text
python scripts/design-integrity.py
python scripts/build_discovery.py --check
node contact/smoke.mjs
node investment/smoke.mjs
node admissions/smoke.mjs
node scripts/design-smoke.cjs
```

The browser check uses an installed Playwright module. Set `PLAYWRIGHT_MODULE` when
it is outside the repository, `AXE_MODULE` to axe.js, `DESIGN_BROWSER` to chromium or
webkit, and `DESIGN_ARTIFACTS` to an optional screenshot directory. For HTTPS use
`DESIGN_TLS_CERT` and `DESIGN_TLS_KEY` pointing to a temporary localhost certificate.
The test accepts that certificate only in its isolated local browser contexts. Never
commit private keys. Test browsers and server close automatically.

## Limits

The design aims at strong visual authorship, useful content, coherent interactions,
and accessible implementation. Award selection remains an external jury decision;
no award, score, full WCAG conformance, physical-device test, or field performance
result is claimed. No real purchase or contact submission is part of these checks.

The change can be rolled back by reverting its merge commit; no data migration or
new service is involved.
